# Ano Hi no Bingo（あの日のビンゴ）

## 概要

小学生の頃、姉と裏紙に書いて遊んでいた2人用ビンゴを
Ruby on Railsで再構築するプロジェクトです。

一般的なビンゴとは異なり、
相手の宣言が自分にとって「お邪魔」になる
心理戦型のビンゴゲームです。

## 制作背景

子供の頃に考案したオリジナルビンゴを、
エンジニアとして再構築したいと思い制作を開始しました。

## MVP（最小実装）

- ソロモード実装
- 勝敗判定ロジック
- 引き分け判定
- 手書き風UI

## 今後の予定
